# StudyFlow — Task Management Web App

StudyFlow is a self-designed and developed Django web application. I created the UI design and implemented the application from scratch.

## Features
- User Authentication
- Task Management Dashboard
- Create and Manage Tasks
- Pomodoro Focus Mode
- User Profile and Settings

## Technologies Used
- Python
- Django
- HTML
- CSS

## How to Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run migrations:
   `python manage.py migrate`
3. Start the server:
   `python manage.py runserver`

Open `http://127.0.0.1:8000` in your browser.
